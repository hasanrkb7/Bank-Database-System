# Bank Database System

These are my SQL labs from the CSE370 Database Systems course at BRAC University. I did them in 2021, in my B.Sc. in Computer Science and Engineering.

The labs cover creating tables, inserting data and queries with joins, subqueries, grouping and aggregate functions. Most of them use a sample bank database with customers, accounts, loans and branches.

Every file has my answers for one lab, with one query for each numbered task. I kept the numbers as I wrote them, so remove the numbers before running a file.
